# Heart Disease Prediction Using Machine Learning

## Overview
This project compares four machine learning algorithms to classify heart disease as Presence or Absence.

## Algorithms
- Support Vector Machine (SVM)
- Decision Tree
- K-Nearest Neighbors (KNN)
- Gaussian Naïve Bayes

## Dataset
`Heart_Disease_Prediction.csv` — 270 records with 13 input features and one target column.

## Methodology
1. Data cleaning and preprocessing
2. Train-test split (80:20)
3. Model training and prediction
4. Performance evaluation and comparison

## Evaluation Metrics
Accuracy, Precision, Recall, F1-score, and Log Loss.

## Technologies
Python, Jupyter Notebook, Pandas, NumPy, Matplotlib, Scikit-learn.

## How to Run
1. Install dependencies: `pip install pandas numpy matplotlib scikit-learn`
2. Open the Jupyter Notebook.
3. Place the dataset in the notebook’s working directory.
4. Run all cells to view the results and comparison plots.

## Output
Model performance comparison, classification reports, confusion matrices, and evaluation plots.
