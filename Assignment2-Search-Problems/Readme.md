# Practical Assignment 2: Problem Solving through Search

## Objective

To implement and evaluate different problem-solving techniques in Artificial Intelligence, including Uninformed Search, Informed Search, Local Search, and Constraint Satisfaction Problems.

## Algorithms Implemented

### 1. Uninformed Search
- Breadth-First Search (BFS)
- Depth-First Search (DFS)

### 2. Informed Search
- Greedy Best-First Search
- A* Search Algorithm

### 3. Local Search
- Hill Climbing Algorithm

### 4. Constraint Satisfaction Problem
- N-Queens Problem using Backtracking

## Features

- Interactive user input for graph-based search algorithms
- Supports custom nodes and edges
- Accepts heuristic values for informed search
- Supports edge costs for A* Search
- Displays the solution path
- Displays the number of nodes/states explored

## Technologies Used

- **Programming Language:** Python
- **IDE/Platform:** Visual Studio Code
- **Libraries:**
  - `collections.deque`
  - `heapq`
